读 API 接口文档

业务接口统一前缀为 /api/v1。成功响应为 application/json; charset=utf-8，所有文本使用 UTF-8。当前数据集版本（meta.dataset_version 为十进制字符串）：{{.Data.Version}}。

通用约定

  • 所有服务可控响应包含 X-Request-ID。
  • 公开读取路由允许 GET、HEAD、OPTIONS。HEAD 与 GET 执行相同校验，仅不返回响应体。
  • 普通 OPTIONS 返回 204 与 Allow 头。
  • 业务接口返回 Cache-Control: no-store。
  • 跨域（CORS）需在部署侧配置允许的 origin；默认不开放跨域。

GET /api/v1/sentences/random

随机返回一条已发布语句。

参数类型默认值限制
categories逗号分隔字符串全部启用分类去重后最多 20 个；非法或未知分类返回 400
min_length十进制整数00–1000
max_length十进制整数300–1000，必须 ≥ min_length

原始查询字符串最多 4096 字节。无匹配数据时返回 404。

{
  "data": {
    "uuid": "75a45fd4-4f2f-45eb-80cb-6f0a7bcdfaf2",
    "content": "今天也要认真写代码。",
    "category": "f",
    "source": "项目自编示例",
    "author": "",
    "length": 10
  },
  "meta": {"dataset_version": "{{.Data.Version}}"}
}

GET /api/v1/sentences/{uuid}

按 UUID 查询单条已发布语句。格式错误返回 400；不存在或未发布返回 404。成功响应结构与随机接口相同。

GET /api/v1/categories

返回所有启用分类（含零语句分类），按 sort_order ASC, code ASC 排列。

{
  "data": [
    {"code": "f", "name": "原创", "count": 120}
  ],
  "meta": {"dataset_version": "{{.Data.Version}}"}
}

错误格式

服务可控错误使用 application/problem+json：

{
  "type": "about:blank",
  "title": "参数无效",
  "status": 400,
  "detail": "max_length 必须大于等于 min_length",
  "request_id": "4eb245ba-2340-420a-8e8b-6f6034c1dcde",
  "code": "invalid-parameter"
}
HTTP 状态code场景
400invalid-parameter参数、UUID、查询编码或不支持的请求实体
401unauthorized手动刷新凭证无效
403cors-denied明确被拒绝的 CORS 预检
404not-found未知路径、缺失语句或没有匹配数据
405method-not-allowed已知路径上方法不受支持
409reload-in-progress已有快照构建任务
500internal-error可恢复内部错误
503not-ready无有效快照或服务正在退出
